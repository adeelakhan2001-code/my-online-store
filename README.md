# HypeCartel

HypeCartel is a modern online shopping website designed for customers in Pakistan.

## About

HypeCartel features a curated selection of useful, trending, and everyday products.

The website is built with:

- HTML
- CSS
- JavaScript

## Features

- Premium responsive ecommerce design
- Product categories
- Product listings
- Shopping cart
- Quantity controls
- Checkout page
- Customer delivery information
- JazzCash payment option
- Easypaisa payment option
- Bank Transfer payment option
- Mobile-friendly layout

## Payment

Payment options are shown during checkout rather than on the homepage.

Available payment methods:

- JazzCash
- Easypaisa
- Bank Transfer

## Project Status

The website frontend is currently being developed. Real payment processing and order management will be connected separately.
